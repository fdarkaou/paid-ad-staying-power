Paid-ad staying power

Paste a PeekPanda paid-ad intelligence response (the stored-library ranking, or one app's chart) and this page shows how long ads stay live: survival curves by format, which button text and copy length last longer, advertisers with the most long-running ads, and weekly launch cadence. Nothing leaves your browser.

Optional: paste a report you saved earlier (CLI --format json or a --state file) to see what changed since then.

Where to get the JSON

The input comes from PeekPanda, an iOS competitor catalogue that keeps dated Meta and TikTok ad-library observations. Call:

curl --get 'https://api.peekpanda.com/v1/paid-ads/intelligence' \
  --header "Authorization: Bearer $PEEKPANDA_TOKEN" \
  --header 'x-genviral-tenancy: personal'

# one app (numeric App Store id)
curl --get 'https://api.peekpanda.com/v1/competitors/ios/6480417616/paid-ads/intelligence' \
  --header "Authorization: Bearer $PEEKPANDA_TOKEN" \
  --header 'x-genviral-tenancy: personal'

Over MCP these are the get_ads actions intelligence and app_intelligence. You need a PeekPanda account and an API key; the paid-ad rankings reference lists every field. The command-line version on GitHub makes the call for you, keeps a weekly diff and can post to Slack or Discord.

These figures describe the ads PeekPanda collected. They are not spend, reach or performance, and a longer run does not prove an ad works. A reading that rests on few ads is marked thin.
